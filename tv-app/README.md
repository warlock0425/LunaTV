# BerserkerTV — Android TV 客戶端

一層薄的 WebView 外殼，讓你在電視上用**遙控器**操作自架的 BerserkerTV 站台。

## 為什麼是 WebView 而不是原生 App

你的需求是「電視上的功能和紀錄要跟手機／網頁完全一樣」。搜尋、陸源譯名橋接、
集數追更、播放紀錄、收藏這些邏輯全都在站台裡，做成原生 App 等於把它們**重寫一遍**，
兩邊只要有一邊改動就會產生行為落差與紀錄不同步。

WebView 外殼直接載入同一個站台，所以：

- 功能永遠一致，不會有「電視版少了某個功能」的情況
- 觀看紀錄、收藏就是同一份資料，不需要另外同步
- 站台更新後電視端立即生效，**不必重新安裝 App**

遙控器的方向鍵由站台內建的空間導航處理（見 `src/lib/spatial-navigation.ts`），
不是靠這個外殼實作。

## 取得 APK

不需要自己安裝 Android Studio。到 GitHub 的 **Actions → Build TV APK**，
點最近一次成功的執行，在下方 **Artifacts** 下載 `BerserkerTV-TV-APK`。

也可以手動觸發：Actions → Build TV APK → Run workflow。

## 安裝到電視

Android TV / Google TV 三種常見方式，擇一即可：

1. **adb（最直接）**

   ```bash
   adb connect 電視IP:5555
   adb install -r BerserkerTV-tv-xxxxxxx.apk
   ```

   需先在電視的「開發人員選項」開啟 USB／網路偵錯。

2. **Send files to TV**：手機與電視各裝一個同名 App，把 APK 傳過去安裝。

3. **USB 隨身碟**：把 APK 放進隨身碟，用電視的檔案管理器安裝。

安裝前需在「設定 → 安全性與限制」允許安裝未知來源的應用程式。

## 首次啟動

會跳出對話框要求輸入站台網址，例如：

```
https://tv.example.com
```

輸入後即記住，之後開啟直接進站。**要更換網址時按遙控器的「選單」鍵**
（部分遙控器標示為三條線或 ☰）即可重新設定，不必重裝。

## 遙控器對應

| 遙控器按鍵     | 行為                             |
| -------------- | -------------------------------- |
| 上／下／左／右 | 移動焦點（由站台的空間導航處理） |
| OK／中鍵       | 開啟目前選取的項目               |
| 返回           | 網頁上一頁；已在首頁時退出 App   |
| 選單           | 重新設定站台網址                 |

## 簽章說明

CI 產出的 APK 以 **debug 金鑰**簽章，目的是讓你能直接側載安裝。這不是上架用的
正式簽章；若日後要上架 Play Store，需另外建立 keystore 並改用正式簽章設定。

## 疑難排解

**遙控器方向鍵沒反應**
外殼載入站台時會自動帶上 `?tv=1` 強制啟用遙控器導航。若仍無效，
請確認站台版本已包含 `TvRemoteNavigation`（v2.8.1 之後）。

**影片無法播放**
確認站台本身在電視的瀏覽器上可以播放。本外殼不介入播放，
播放能力取決於電視的 WebView 版本對 HLS 的支援程度。

**畫面過大／過小**
電視的顯示縮放由系統設定決定，可在電視的「顯示」設定調整。
